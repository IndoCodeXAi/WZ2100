# Warzone 2100 untuk Android (build otomatis)

1. Buat repositori GitHub baru (private) dan upload isi folder ini (termasuk `.github` dan `wz.jks`).
2. Buka tab Actions, pilih "Build Warzone 2100 Android", lalu Run workflow.
3. Tunggu selesai (bisa 1 sampai 3 jam). Unduh artifact `Warzone2100-APK`.
4. Kalau gagal, unduh artifact `build-log` atau salin bagian error dari log, lalu kirim ke saya.
